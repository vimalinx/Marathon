# Code Of Conduct

## Expected Behavior

- Be direct, respectful, and technically honest.
- Separate facts from assumptions.
- Give actionable feedback.
- Respect project boundaries and maintainer decisions.

## Unacceptable Behavior

- Harassment or personal attacks
- Publishing private credentials or sensitive local environment data
- Bad-faith issue filing or deliberately disruptive contributions

## Enforcement

Project maintainers may remove comments, issues, or contributions that violate this standard.

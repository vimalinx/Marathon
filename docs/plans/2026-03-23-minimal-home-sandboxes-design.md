# Minimal Home And Sandboxes Design

**Goal:** 把 Marathon Web UI 从“多功能控制台”收缩成“实验主屏 + 独立沙盒页”，让主页一眼就知道当前实验在做什么。

## 用户意图

当前主页信息过量，沙盒列表、运维入口、启动入口、主屏输出同时出现，导致第一次打开时不知道应该看哪里、点哪里。

这次改动的核心不是新增功能，而是重新组织信息：

- 主页只回答“当前实验在干嘛”
- 沙盒页只回答“有哪些沙盒、它们现在什么状态”
- 复杂配置和运维不再占主页主视野

## 信息架构

### 主页 `/`

主页只保留最小必要结构：

1. 顶部导航
   - 产品标题
   - 跳转到沙盒页的入口
   - 当前时间

2. 当前实验卡片
   - 当前沙盒名
   - 当前 run 状态
   - 模式：任务模式 / 自由玩法
   - 简洁说明文字

3. 启动动作区
   - 明确任务输入框
   - `启动任务模式`
   - `启动自由玩法`
   - `停止 AI`

4. 最新输出区
   - 最近模型输出
   - 最近动作摘要
   - 最近几轮概括

5. 极简空状态
   - 如果没有选中沙盒或当前沙盒没有 run，只给一句指引，提示去沙盒页选择

### 沙盒页 `/sandboxes`

沙盒页专门承载：

- 沙盒列表
- 每个沙盒的状态、最近 run、资源指标摘要
- 选择当前沙盒并返回主页
- 启停容器、进入该沙盒的主屏

先不把全部运维功能搬过去，先保留最基本的浏览和进入。

## 视觉方向

采用米白黑灰极简风格：

- 背景：米白 / 纸面色
- 主文字：近黑
- 辅助文字：中灰
- 分隔：浅灰细边框
- 强调按钮：黑底白字
- 次级按钮：白底黑边

避免：

- 深色大面积底色
- 紫黄高对比渐变
- 多列密集信息墙

## 技术方案

1. 保留现有 API，不大改后端数据结构
2. 新增一个静态页面 `host/static/sandboxes.html`
3. 扩展 `host/web_ui.py` 的静态路由，让 `/sandboxes` 可访问
4. 重写主页 `host/static/index.html` 的布局和配色
5. 新增少量测试，覆盖：
   - `/sandboxes` 静态路由
   - 首页与沙盒页关键文案存在

## 范围控制

这次不做：

- 完整设置页重设计
- 完整运维页重设计
- 前后端状态管理重构
- 新增复杂筛选、搜索、分页

先把主页减到最小、把沙盒挪出去，之后再一点点加。

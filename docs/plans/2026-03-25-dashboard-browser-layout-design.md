# Dashboard Browser Layout Design

**Goal:** 把首页改成内容浏览器式布局，借鉴 NotebookLM 的信息组织方式，但继续使用 Marathon 当前的浅色配色体系。

## 用户意图

用户想借的是布局，不是配色：

- 首页先像一个“对象浏览器”
- 先看一排重点卡片
- 再看一片最近活跃卡片
- 少一点运维面板感，多一点“打开即浏览”的感觉

## 设计原则

1. 借鉴 NotebookLM 的分层方式，不照抄皮肤。
2. 保留现有米白、黑灰配色。
3. 首页主任务不是一个大面板，而是一排“当前重点”卡片。
4. 下方是“最近活跃”网格。
5. 卡片先表达：
   - 谁在跑
   - AI 最近在想什么
   - 最近在做什么

## 信息架构

### 顶部控制条

- `全部`
- `正在运行`
- `最近活跃`
- 右侧 `新建任务`
- 自动刷新仍保留，但不做成显眼运维控件

### 当前重点

- 横向滚动卡片
- 放 3 到 4 张最值得看的容器
- 排序规则：
  1. 正在运行的任务优先
  2. 其次最近运行
  3. 其次运行中的容器

每张重点卡片显示：

- 容器名
- 状态
- 运行方式
- AI 最新意图
- 最近动作
- 时间
- 详情入口

### 最近活跃

- 网格卡片
- 第一张保留“新建任务”入口
- 其余显示非重点容器

每张卡片只显示：

- 容器名
- 状态
- 最近 run
- 一句摘要
- 更新时间

## 交互

- 点击卡片进入 `/container?container=...`
- 顶部筛选实时切换重点区和网格区
- 自动刷新：
  - 有活动任务时 4 秒
  - 没有活动任务时 12 秒

## 范围控制

这次不做：

- 深色模式重皮肤
- 首页完整日志
- 图表
- 新后端接口

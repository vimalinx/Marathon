# Desktop Home And Journal Redesign

**Goal**

把 Marathon 的桌面端首页和容器详情页从“日志直接堆在卡片里”的后台样式，改成“封面浏览 + round 时间线”的观察界面。

**Context**

- 首页当前会把 `Done / Next / Thought` 原文直接塞进 featured 和 browse 卡片，长内容会把卡片拉到不可浏览的高度。
- 容器首页卡片的主点击区不明确，用户需要盯着小按钮找入口，违背“扫一眼就进去”的桌面浏览习惯。
- 容器详情页当前把每一轮近似当成长文章顺序堆叠，缺少节奏、折叠和结束感。

**Design Direction**

1. 首页改成桌面优先的“编辑封面”
   - `当前重点` 改为 2 列重点卡，不再横向滚动。
   - 每张卡只显示少量高价值信息：容器名、状态、最近一句摘要、下一步一句、更新时间、轮次。
   - 卡片整体可点击，点击任意空白区域直接进入容器页。
   - 保留一个次级动作用于“基于此新建”，但详情不再依赖小按钮。

2. 最近活跃区改成统一高度的浏览卡
   - 普通卡只展示一条摘要和一条下一步 teaser。
   - 通过文本截断和固定布局保证桌面端扫读效率。
   - “新建任务”卡保留，但改成明显入口卡，而不是普通内容卡。

3. 容器详情页改成 round 时间线
   - 每轮渲染成一个可展开的 round 条目，而不是直接铺开全文。
   - 最新一轮默认展开，旧轮次默认折叠。
   - 折叠态只展示 round 标题、时间、run id、状态和一句摘要。
   - 展开态再显示 `Done / Next / Thought` 与原始输出折叠区。
   - 时间线底部增加结束提示，给页面明确终点。

4. 视觉语言
   - 保留当前米白纸面基调，不引入另一套完全不同的审美。
   - 首页更像“封面/选题页”，详情页更像“研究日志时间线”。
   - 重点放在层级、点击区、卡片密度和节奏感，不做无关的功能膨胀。

**Success Criteria**

- 桌面端首页不再出现千像素级超长 featured 卡。
- 首页任意容器卡都能直接点击进入容器页。
- 容器详情页默认只展开最新一轮，旧轮次折叠，不再像无尽长文。
- `Done / Next / Thought` 仍可见，但只在需要时展开，不再压垮首屏浏览。

**Out Of Scope**

- 专门优化移动端布局。
- 改动 API 数据结构。
- 改动 host 侧路由或容器运行逻辑。

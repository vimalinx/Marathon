# Design Lab Simplification Design

**Goal:** 把设计实验室从“解释界面方案”改成“直接看实验数据”，减少重复说明、重复模块和概念切换。

## 问题

当前设计实验室的问题不在数据缺失，而在页面太会说话：

- 首页既讲怎么选上下文，又讲怎么比较方案，还讲每套方案看什么。
- 方案页里同一份数据被拆进很多近义模块。
- 每个区块都附带一段“为什么存在”的说明，读页面比读实验更费脑子。

## 设计原则

1. 首页只做两件事：选上下文、进方案。
2. 每个方案页最多三个主块。
3. 说明文案缩到一句话以内，优先让真实数据占主视野。
4. 自我修改不再默认占一个大区，只有在确实发生时才突出显示。
5. 继续保留三套方案，但差异只体现在排布方式，不再靠大量解释文案区分。

## 信息架构

### `/design-lab/index.html`

- 标题
- 一句说明
- 上下文输入表单
- 一行概览摘要
- 三张方案卡片

删除：

- 评价 rubric
- 重复说明块
- 每张卡片下的长列表

### `design-consultation.html` 观察台

改成三个块：

1. 当前
   - 当前焦点
   - 运行状态
   - 已完成轮次
   - 自我修改状态
   - 最新摘要 / 最近命令 / 任务说明
2. 时间线
   - 最近几轮
3. 输出
   - 命令
   - 模型回复
   - stdout / stderr
   - 工作区快照

### `ui-ux-pro-max.html` 控制台

改成三个块：

1. 状态
   - 焦点
   - 状态
   - 轮次
   - 返回码
   - 自我修改
2. 动态
   - 最近活动列表
3. 输出
   - 原始产物网格

### `penpot-uiux-design.html` 流程台

改成三个块：

1. 上下文
   - 当前焦点
   - 容器
   - 状态
   - 最近变化
2. 时间线
3. 细节
   - 自我修改摘要
   - 最近命令 / 回复 / 输出
   - 工作区快照

## 共享文案调整

- 首页概览摘要改成一句短状态。
- 空状态和错误态保留，但统一缩短为一句主句 + 一句必要补充。
- 不再使用“当前概况 / 关键指标 / 生命周期”这类重复概念词。

## 不做的事

- 不改后端接口
- 不改设计实验室的入口方式
- 不把三套方案收敛成单页
- 不做新的交互控件或筛选器
